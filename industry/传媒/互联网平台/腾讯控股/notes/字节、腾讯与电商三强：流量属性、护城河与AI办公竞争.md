# 字节、腾讯与电商三强：流量属性、护城河与AI办公竞争

## TL;DR

本报告回答的关键问题是：字节与腾讯是否“你死我活”、两家护城河谁更深更宽、字节“一统天下”是否成立，以及作为腾讯持有者如何给其AI投入与竞争位置定价。最重要的可争辩判断有两个：**腾讯护城河更深，字节护城河更宽**，二者是底层流量属性错位、表层高强度交火、局部竞合；**字节赢下了注意力与商业化效率的上半场，但“一统天下”受广告加载率、AI资本开支、社交链缺失和重度内容生态约束**。

这些判断成立依赖两个机制：关系链产生迁移成本与社交资本，算法效率依赖持续资本开支和内容供给；一旦广告加载率见顶或AI整合失败，宽度优势不能自动转化为利润优势。本期最稀缺的张力是：柏基、张坤等把腾讯当核心底仓，而李录、段永平式框架只在极端赔率下重注拼多多、对腾讯“尊重但不重仓”；AI办公三家中WorkBuddy先发数据最硬，但千问办公的B端纵深和豆包的多模态弹性使“三分天下”成为基准情景。

## 核心结论

1. **字节与腾讯不是“你死我活”，而是底层流量属性错位下的高强度竞合。** 机制是娱乐内容流量与社交关系流量对应不同核心资产：前者靠算法与内容供给，后者靠关系链与信任沉淀；二者争用户总时长和广告预算，但护城河不在同一口井里。证据是字节系时长占比41.8%、腾讯系28.6%，但腾讯仍握有12.8亿去重用户和极高迁移成本。

2. **腾讯护城河更深，字节护城河更宽。** 机制是腾讯依赖单边网络效应和关系链锁定，字节依赖数据网络效应和算法效率覆盖；深度决定“更难被推翻”，宽度决定“更难被追上”。证据是微信人均打开1071次 vs 抖音319次，腾讯净利率约29.87% vs 字节16.7%。边界：腾讯AI整合偏慢，字节维持宽度需持续高投入。

3. **短视频/短剧难替代游戏，娱乐不是铁板一块。** 机制是被动内容消费与主动互动参与在需求层次、时间场景、沉没成本上不同；短剧抢碎片时间，游戏占整块时间与社交时间。证据是红果短剧DAU 1.68亿、人均125分钟，但腾讯游戏长青公式仍是“产品品质×社交关系链×长线运营×内容生态”。边界：轻度用户和买量渠道会交叉，但不构成核心替代。

4. **“字节一统天下”不成立。** 机制是广告加载率接近物理边界、AI资本开支稀释利润、社交关系链缺失、重度游戏与内容治理需要长期生态能力。证据是抖音广告加载率约15%而视频号仅3%—5%，字节净利率从26%降至16.7%，战略收缩为抖音+豆包两条主线。

5. **Seedance的协同效应真实，但属于“非对称纵深”。** 机制是多模态能力同时嵌入豆包/抖音交易闭环、火山引擎ToB引流和内容生态数据飞轮。证据是海外收入占比达50%，腾讯位列其国内客户前三，火山引擎国内MaaS份额49.5%。边界：字节同时承认大语言模型与海外领先差距拉大，优势来自聚焦取舍而非全面碾压。

6. **电商三强是同一“交易”底色、三条护城河路径。** 机制是阿里做商家经营操作系统、京东做物理履约、拼多多从极致效率转向供应链。证据是京东重资产扩张出现单季亏损，拼多多现金及短期投资4223亿元、资本开支仅11.45亿元，阿里CMR变现路径最清晰。边界：阿里缺高频自有入口，京东利润代价高，拼多多前端红利衰减。

7. **大师不是不看好腾讯，而是“尊重但不重仓”。** 机制是腾讯护城河是共识性的深，市场很少给出“好公司被当烂公司定价”的极端赔率窗口；大师重仓需护城河×估值×确定性×能力圈同时成立。证据是柏基将腾讯列为中国股票组合第一大重仓约12%，张坤、赵枫亦为第一大重仓，段永平称“非卖品”但仓位约1%；李录买腾讯音乐是逆向烟蒂型交易。

8. **腾讯AI有三个盲区：关系链可能成“锁”、自由现金流转负、海外游戏地缘尾部风险。** 机制是元宝C端失败后转WorkBuddy，2026Q2自由现金流净流出138亿元，Riot/Epic股权面临强制处置审查。边界：WorkBuddy与企微协同已落地，自由现金流是你已知变量，地缘风险属低概率高冲击、宜留估值折让而非卖出信号。

9. **AI办公中长期“三分天下”概率最高。** 机制是WorkBuddy守入口与生态货币化，千问办公守B端纵深与云闭环，豆包工作争飞书上下文与多模态交付。证据是WorkBuddy多端月活3235万、付费毛利媲美腾讯云；千问办公注册3000万且过半来自企业员工；豆包工作月活约9万，受飞书入口规模约束。边界：WorkBuddy先发窗口收窄，豆包入口是物理天花板。

10. **腾讯AI投入的可定价产出，应跟踪WorkBuddy付费坐席、续费率和企微转化。** 机制是腾讯用B端组织链而非C端注意力为AI寻找付费场景。证据是企微覆盖1400万企业、每日服务7.5亿微信用户，WorkBuddy付费坐席约14万。边界：若2027年付费坐席未破50万且企微转化平庸，WorkBuddy更接近防守性占位而非增长引擎。

## 隐含推理与未明说暗示

1. **推论：腾讯的“深”在AI时代可能同时是一把“锁”。** 依据：元宝月活约5735万，远低于豆包3.45亿；春节10亿红包后DAU暴跌64%；微信熟人场景对AI整合的隐私与体验约束更重。边界：若微信内AI找到低打扰、高留存的形态，锁可转为入口；待验证。

2. **推论：字节的宽度优势正在接近变现的物理边界。** 依据：抖音广告加载率约15%，视频号仅3%—5%；净利率降至16.7%，AI资本开支高企。边界：若海外、电商、云找到第二变现曲线，宽度仍可延伸；否则“时长→广告”引擎效率递减。

3. **推论：李录买腾讯音乐不是看好音乐平台长期护城河，而是现金垫底下的极端赔率交易。** 依据：现金占市值近50%，扣除现金后核心业务约9倍PE，仓位仅1.5%且远低于谷歌44%；音乐平台缺乏网络效应。边界：若汽水音乐免费模式持续分流，烟蒂价值可能被时间侵蚀。

4. **推论：段永平“非卖品但1%仓位”暴露了腾讯的确定性折价。** 依据：他称腾讯确定性比苹果小不少、下不了大决心多买，同时称买腾讯比存银行好。边界：若AI办公和海外游戏增量验证，确定性折价可能收窄；否则“尊重但不重仓”仍是理性选择。

5. **推论：WorkBuddy的真实价值不在月活第一，而在企微组织链分发。** 依据：企微覆盖1400万企业、7.5亿微信用户，WorkBuddy进入通讯录并共用账号权限，付费毛利已可媲美腾讯云。边界：若企微渠道付费转化率不显著高于自然渠道，先发优势更接近营销故事而非生态收入故事。

6. **推论：豆包工作的产品能力被入口规模压制，字节可能被迫在飞书之外开新企业入口。** 依据：飞书PC月活约193.5万，远低于企微2030万；豆包工作月活约9万，仅为WorkBuddy的6%；字节已将飞书产品团队并入豆包。边界：若字节用C端势能强推企业入口，变数重新打开；否则天花板可见。

7. **推论：千问办公“注册3000万”更多是试用脉冲，真实壁垒在钉钉组织数据和阿里云销售管道。** 依据：真实月活约158万，超半数注册来自企业员工；产品归钉钉、销售归阿里云，形成组织数据→模型推理→云消耗闭环。边界：个人桌面体验短板若长期不补，自下而上渗透受限。

8. **推论：市场对腾讯海外游戏地缘风险的定价不足。** 依据：海外游戏收入774亿元、占游戏总收入35%以上，Riot/Epic股权审查指向强制处置而非普通采购限制；市场仍按线性增长定价。边界：低概率高冲击，应在海外游戏分部估值中留折让，而非作为立即卖出信号。

## 一、核心结论

- 字节与腾讯不是“你死我活”，而是**底层流量属性错位、表层高强度交火、局部竞合**。
- **腾讯护城河更深，字节护城河更宽**：腾讯深在“人与人的关系链不可迁移”，字节宽在“算法与内容效率的规模化覆盖”。
- “字节一统天下”夸大其词。字节赢的是**注意力与商业化效率**，但面临广告加载率、AI资本开支、社交关系链缺失、重度内容生态等约束。
- 电商三强同样是“同一交易底色、三条护城河路径”：阿里宽在商家经营生态，京东深在物理履约，拼多多正在从“前端流量效率”转向“后端供应链”。
- AI办公中长期**“三分天下”概率最高**：WorkBuddy守入口与生态货币化，千问办公守B端纵深与云闭环，豆包工作弹性大但受飞书入口规模约束。

## 二、流量属性与护城河：腾讯深，字节宽

| 维度       | 腾讯                                       | 字节                                     |
| ---------- | ------------------------------------------ | ---------------------------------------- |
| 流量属性   | 关系链流量：社交、信任、身份沉淀           | 内容兴趣流量：算法、娱乐消费、即时满足   |
| 娱乐形态   | 互动参与型娱乐（游戏）+社交化娱乐          | 内容消费型娱乐（短视频、短剧、小说）     |
| 护城河方向 | **深**：迁移成本极高，关系链搬不走         | **宽**：覆盖广、效率高，但用户锁定偏弱   |
| 核心风险   | 关系链活跃度被内容形态缓慢稀释；AI整合偏重 | 维持宽度需持续高强度投入；缺乏强关系锁定 |

**关键判断：**

- 短视频/短剧与游戏都叫娱乐，但一个是“看别人给的情绪”，一个是“自己参与创造的情绪”，**替代弹性低**。
- 腾讯游戏长青公式：**产品品质 × 社交关系链 × 长线运营 × 内容生态**。社交链是乘数，不是免死金牌。
- 字节模式接近“时长→广告加载→收入”，广告加载率接近边界后，**时长优势不会无限转化为利润优势**。

## 三、电商三强：同一“交易”底色，三种护城河

|            | 阿里                   | 京东                     | 拼多多                       |
| ---------- | ---------------------- | ------------------------ | ---------------------------- |
| 流量属性   | 搜索+商业意图          | 目的性购买+信任履约      | 社交裂变+低价心智            |
| 护城河核心 | 商家经营操作系统       | 自营供应链与仓配履约     | 极致效率，正向供应链转型     |
| 深在哪里   | 商家工具与数据嵌入深度 | 重资产网络的物理壁垒     | 成本结构带来的价格可持续性   |
| 宽在哪里   | 品类与商家生态广度     | 履约场景延伸（即时零售） | 下沉市场与供给侧覆盖         |
| 弱点       | 缺自有高粘性流量入口   | 重资产扩张利润代价高     | 前端红利衰减，后端壁垒建设中 |

**一句话：** 京东护城河“物理最深但扩张最贵”，阿里“生态最宽但流量根基偏虚”，拼多多“前浅后深、正在换轨”。

## 四、字节时代论与Seedance协同

**“字节一统天下”不成立的理由：**

1. 广告加载率接近物理边界，变现不是无限的。
2. 净利率因AI投入被稀释，需用成熟流量机器现金押注下一台机器。
3. 社交关系链缺失是结构性短板，内容粘性≠关系粘性。
4. 重度游戏、内容治理需要长期生态能力，流量不能直接抹平。

**Seedance的协同效应是真实的，但属于“非对称纵深”：**

- 技术：音画同步、角色一致性、导演级运镜，从“生成片段”走向“叙事生产”。
- 商业化：海外收入占比达50%，国内客户包括腾讯、B站；火山引擎MaaS份额领先。
- 协同：与豆包/抖音电商交易闭环、火山引擎ToB引流、内容生态数据飞轮。
- 但字节同时承认大语言模型与海外领先差距拉大，战略收缩为**抖音+豆包两条主线**，说明优势是聚焦取舍的结果，不是全面碾压。

## 五、投资大师与腾讯：为什么“尊重但不重仓”

**事实校正：并非没有高手买腾讯。**

- 柏基投资：腾讯为其中国股票组合**第一大重仓**，占比约12%。
- 张坤、赵枫：腾讯为各自基金**第一大重仓**；萧楠持仓占比约9.56%。
- 张磊/高瓴：2005年创立时**首笔资金全部投腾讯**。
- 段永平：称腾讯为“非卖品”，持续买入，但仓位约**1%**，认为确定性不如苹果。

**为什么大师们少有“极端重仓”：**

- 腾讯护城河是**共识性的深**，市场很少给出“好公司被当烂公司定价”的极端赔率窗口。
- 大师超额收益多来自“好公司被暂时当成烂公司定价”，如李录买拼多多时的低估值+强现金流。
- 芒格买阿里，是在“中国资产便宜+可理解”框架下的例外决策，不等于否定腾讯。

**李录买腾讯音乐（TME）：**

- 2026Q1建仓659万股，Q2仍持有不变，仓位约1.5%，为其美股第九大重仓。
- 逻辑：股价大跌后**逆向买入**；账上现金占市值近50%，扣除现金后核心业务估值约9倍PE；音乐订阅低投入、高现金流。
- 性质：有严格仓位限制的**逆向“烟蒂型”投资**，不是长期核心资产。

## 六、腾讯AI的三个盲区（你已认知，记录备查）

1. **关系链在AI时代可能成“锁”**：元宝C端失败，腾讯转WorkBuddy，从注意力争夺转向B端付费场景。
2. **自由现金流转负**：2026Q2自由现金流净流出138亿元，回购-分红飞轮受AI资本开支侵蚀。
3. **Riot/Epic股权地缘政治尾部风险**：低概率、高冲击，市场尚未充分定价。

## 七、AI办公三足鼎立：WorkBuddy vs 豆包工作 vs 千问办公

|        | WorkBuddy                             | 豆包工作                                 | 千问办公                                        |
| ------ | ------------------------------------- | ---------------------------------------- | ----------------------------------------------- |
| 路线   | 入口平台+生态货币化                   | 飞书融合+模型开放                        | B端纵深+云反哺                                  |
| 优势   | 先发规模、企微/微信入口、付费毛利健康 | 多模态交付、飞书协作上下文、字节销售体系 | 钉钉2600万企业组织、阿里云500万客户、组织级付费 |
| 约束   | 先发窗口被挤压，需证明续费与企微转化  | 飞书入口规模小，独立月活低               | 个人桌面体验弱，企业决策周期长                  |
| 护城河 | 企微关系链与组织入口                  | 飞书上下文+字节多模态                    | 组织数据→模型推理→云消耗闭环                    |

**中长期判断：**

- **三分天下概率最高**，三家各守一个维度，而非同质瓜分。
- WorkBuddy**确定性最高**：入口与生态货币化已验证。
- 千问办公**B端纵深最扎实**：付费方厚、云闭环自我强化。
- 豆包工作**弹性最大但约束最硬**：产品能力全，入口规模是物理天花板。

**跟踪锚点（腾讯持有者）：**

1. WorkBuddy付费坐席能否在2027年突破50万以上。
2. Buddy One打包订阅的**续费率**，而非首次付费用户数。
3. 企微渠道带来的企业付费转化率是否持续高于自然渠道。

## 八、一句话收束

**腾讯的“深”与字节的“宽”，是两种流量基因长出的两种极致；AI办公的三分天下，则是腾讯用B端组织链而非C端注意力，为自身AI投入寻找可定价产出的关键试验场。**
